# Архитектурный план проекта «ИИ-Арена» (AI Reality Show)

## 🏛️ 1. Элементы структуры данных
*   `current_context` — строковая переменная в памяти Python. Хранит реплики только текущего раунда (максимум 9 строк). В конце каждого раунда полностью стирается.
*   `summary.txt` — текстовый файл на жестком диске. Используется для накопления итоговых вердиктов от ИИ-Судьи.

## 👥 2. Конфигурация ИИ-Агентов (Роли для Ollama)
*   **Агент А (Персонаж 1):** Имеет жесткую роль и одну фокусную цель, противоречащую цели Агента Б. Обязан реагировать на действия соперника.
*   **Агент Б (Персонаж 2):** Имеет противоположную роль и цель. Обязан реагировать на действия Агента А.
*   **Агент В (Режиссёр хаоса):** Не читает диалог. Напрямую из Python поставляет случайную экстремальную ситуацию из заготовленного списка.
*   **Агент Г (Судья-Летописец):** Анализирует лог раунда из 9 строк. Задача — сжать сюжет раунда, зафиксировать ключевой поворот и объявить имя победителя.

## 🔄 3. Пошаговый алгоритм бесконечного цикла (while True)

Шаг 1. Старт Раунда: Python делает запрос к Олламе с промптом PROMPT_DIRECTOR [🔒].
 Модель сама генерирует новое случайное событие [🔒].
 Полученный текст Python записывает первой строкой в переменную current_context.

### Шаг 2. Игровой диалог (Внутренний цикл на 8 итераций)
*   **Ход Агента А:** Передаем `current_context` в Ollama ➡️ Получаем реплику ➡️ Python дописывает её в `current_context`.
*   **Ход Агента Б:** Передаем обновленный `current_context` в Ollama ➡️ Получаем реплику ➡️ Python дописывает её в `current_context`.

### Шаг 3. Судейство и Фильтрация
*   Диалог раунда останавливается.
*   Python передает всю строку `current_context` (9 реплик) Агенту Г (Судье).
*   Судья генерирует краткий вердикт и определяет победителя раунда.

### Шаг 4. Фиксация результатов
*   Python открывает файл `summary.txt` в режиме добавления данных (`"a"`).
*   Записывает туда сформированный вердикт Судьи.

### Шаг 5. Очистка контекста
*   Python полностью обнуляет переменную `current_context`.
*   Счетчик раунда сбрасывается. 
*   Цикл возвращается на Шаг 1 для запуска новой эпохи.
