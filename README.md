# AI Arena

Симулятор текстовой арены: два ИИ-агента попадают в экстремальную ситуацию
и пытаются достичь противоположных целей. Судья оценивает раунд и выносит
вердикт, корректор правит текст. В `summary.txt` сохраняются итоги эпох.

## Как это работает

Одна эпоха состоит из этапов:

1. **Директор** — придумывает локацию, событие и двух знаменитостей
   с противоположными целями.
2. **Диалог** — агенты делают по 4 хода, реагируя на действия друг друга.
3. **Судья** — читает лог и выносит вердикт: сюжетный итог и победителя раунда.
4. **Корректор** — исправляет грамматику и пунктуацию вердикта.
5. **Запись** — итог эпохи сохраняется в `summary.txt`.

Всё работает локально через [Ollama](https://ollama.com).

## Установка

1. Установи [Ollama](https://ollama.com).
2. Скачай модели:

       ollama pull qwen2.5:14b
       ollama pull qwen2.5:7b

3. Установи Python-зависимости:

       pip install -r requirements.txt

## Запуск

    python main.py

Остановить — `Ctrl+C`. Итоги эпох пишутся в `summary.txt`.

## Пример вывода

    ЭПОХА: 1
    СОБЫТИЕ: Тонущий Титаник, палуба наклоняется.
    Сюжетный итог: Илон Маск попытался запустить ракету с палубы,
    но Бузова перехватила управление и улетела одна.
    Победитель раунда: Ольга Бузова

## Структура проекта

- `main.py` — точка входа
- `simulator.py` — цикл эпохи
- `llm.py` — обёртка над Ollama
- `parser.py` — парсинг XML-ответов модели
- `storage.py` — запись итогов эпох в файл
- `prompts.py` — тексты промптов
- `config.py` — настройки (модель, параметры, пути)
- `tests/` — юнит-тесты парсера

## Зависимости

- Python 3.10+
- Ollama с моделями `qwen2.5:14b` и `qwen2.5:7b`
